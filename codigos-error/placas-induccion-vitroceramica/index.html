Códigos de error de placas de inducción y vitrocerámica Bosch, Siemens y Balay

Los códigos son orientativos: Bosch, Siemens y Balay comparten muchos códigos, pero el significado exacto puede variar según el modelo y el año. En muchos modelos aparecen como E18, E:18 o F18. Si el error se repite tras probar la solución, pide un técnico. Si el error vuelve a aparecer tras probar la solución, pide un técnico.

CódigoQué significaQué puedes hacer
E (sola)Hay un código de error más largo.Mantén pulsada la zona afectada para ver el código completo y anótalo.
F2La electrónica se ha sobrecalentado tras mucho tiempo a alta potencia.Espera a que se enfríe. Si se repite a menudo, revisa la ventilación del mueble o pide un técnico.
U400La placa está mal conectada a la red eléctrica.Desconéctala de la luz y que un técnico revise la conexión.
H / hIndicador de calor residual. No es una avería.La zona sigue caliente. Desaparece cuando se enfría.
Códigos numéricos (22, 32, 132…)Su significado depende del modelo exacto.Anota el código y el E-Nr de la etiqueta. El técnico lo identificará.
